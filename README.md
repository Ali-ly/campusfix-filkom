# CampusFix FILKOM

Prototipe web pelaporan kerusakan fasilitas Fakultas Ilmu Komputer Universitas Brawijaya. Dibuat dengan HTML, CSS, dan JavaScript tanpa framework.

## Menjalankan

Buka `index.html` di browser, atau jalankan:

```sh
python3 -m http.server 8765
```

Kemudian buka http://localhost:8765.

## Fitur

- Pilihan kategori fasilitas dan validasi form.
- Gedung G dengan G1–G6; gedung F lantai 2–12, masing-masing 8 ruangan.
- Pratinjau foto JPG/PNG, maksimal 5 MB.
- Waktu kejadian dengan pilihan AM/PM.
- Progres isian, ringkasan, dan tiket simulasi.
- Tampilan responsif dengan identitas FILKOM UB.

Ini adalah proyek tugas mahasiswa, bukan layanan resmi FILKOM UB. Laporan belum dikirim atau disimpan di server. Sumber logo tercantum di `assets/SOURCES.md`.
